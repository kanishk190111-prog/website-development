Unequal Grids

Example 1 8/12 + 4/12 Layout

Classic blog layout: Main content takes 8 columns (66.67%) and sidebar takes 4 columns (33.33%). Total = 12/12 = 100% width.

/* 8 columns + 4 columns = 12 columns total */
.col-8 { grid-column: span 8; } /* 66.67% width */
.col-4 { grid-column: span 4; } /* 33.33% width */
